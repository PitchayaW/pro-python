# เรียนโปรแกรมไพธอน ผ่าน https://pro-python.streamlit.app

เว็บแอปสำหรับสอน Python เบื้องต้นแบบ interactive ใช้ Streamlit
นักศึกษาเขียนโค้ดในเบราว์เซอร์ได้จริง มีระบบตรวจคำตอบอัตโนมัติ
และบันทึกความก้าวหน้าลง Google Sheet ให้อาจารย์ตรวจ

## หัวข้อ
```
python-course/
├── บทที่ 0 — ความเป็นมาของไพธอน

├── บทที่ 2 — ตัวแปรและ Data Type 
├── บทที่ 3 — Data Structure 
├── บทที่ 4 — Conditions

├── บทที่ 6 — Functions
```

## การบันทึกความคืบหน้า

- ล็อกอินครั้งเดียว ระบบจะจำไว้ใน URL (`?sid=...&email=...`) refresh หรือบุ๊กมาร์กลิงก์ไว้ กลับมาแล้วเข้าสู่ระบบให้อัตโนมัติ
- โค้ดถูกบันทึกลง Google Sheet ทุกครั้งที่กด "รันโค้ด" (status `draft`) และ "ตรวจคำตอบ" (status `passed`/`failed`) กลับมาจะเห็นโค้ดเดิมใน editor
- เคยผ่านแล้วนับว่าผ่านถาวร แม้ส่งครั้งหลังจะผิด
- อ่านชีตครั้งเดียวต่อเซสชัน (cache กลาง 60 วินาที) เพื่อไม่ให้ชนโควตา Google Sheets API เมื่อทั้งห้องใช้พร้อมกัน ถ้าบันทึกไม่สำเร็จจะเก็บไว้ในคิวแล้วส่งซ้ำอัตโนมัติ
- จำนวนแบบฝึกหัดของแต่ละบทกำหนดไว้ที่ `utils/lessons.py` (ถ้าเพิ่ม/ลบข้อ ให้แก้ค่า `total` ด้วย)

## ข้อจำกัดที่ควรรู้

- Streamlit Community Cloud จำกัด RAM ที่ 1 GB ต่อแอป ถ้านักศึกษาเข้าพร้อมกันมากและรันโค้ดหนัก ๆ พร้อมกันอาจหน่วง
- แอปจะ "หลับ" ถ้าไม่มีคนใช้นานเกินไป และใช้เวลาราว 10-30 วินาทีในการ "ตื่น" ตอนมีคนเข้าใหม่
- การรันโค้ดนักศึกษาแต่ละครั้งใช้ subprocess แยก มี timeout 5 วินาทีต่อครั้ง กัน infinite loop
